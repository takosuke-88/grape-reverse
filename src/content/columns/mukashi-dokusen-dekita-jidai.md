<h1 class="text-3xl font-bold mb-6 text-gray-900 dark:text-white">
  「昔の台が良かったのではなく、時代が良かった」　独占できた頃の話
</h1>
</div>

<p>前回、<strong>「今の台の方が昔より面白い」という店長発言</strong>について書きました。<strong>台の作り込みは今のほうが上だが、「面白い」に3つの軸が混ざっている</strong>という整理です。</p>

<p>そして最後に、こう書きました。<strong>面白かったのは、台ではなかったのかもしれない</strong>と。</p>

<p><strong>その答えらしき投稿が、同じ論争の延長で流れていました。</strong></p>

<h2>「いい時代でしたよ」</h2>

<p>内容を要約すると、こうです。</p>

<p><strong>日当5万円の一発台を、毎日同じ人が打っていた。それなのに1か月据え置き。横取りするやつもいなかった。いい時代でしたよ</strong>——。</p>

<p><strong>この投稿、台の性能について一言も触れていません。</strong></p>

<h2>ここで語られているのは「独占」である</h2>

<p>一文ずつ分解すると、何が良かったのかがはっきりします。</p>

<div class="overflow-x-auto my-6">
<table>
  <tr>
    <th>証言</th>
    <th>何を意味するか</th>
  </tr>
  <tr>
    <td>日当5万円</td>
    <td>期待値が異常に高い台が実在した</td>
  </tr>
  <tr>
    <td>毎日同じ人が打っていた</td>
    <td><strong>他に気づく人がいなかった</strong></td>
  </tr>
  <tr>
    <td>1か月据え置き</td>
    <td>店も動かさなかった、あるいは気づいていなかった</td>
  </tr>
  <tr>
    <td>横取りするやつがいなかった</td>
    <td><strong>競合が存在しなかった</strong></td>
  </tr>
</table>
</div>

<p><strong>つまり、これは独占の話です。</strong></p>

<p>台が面白かったのではありません。<strong>その台を、自分だけが知っていた。</strong> それが「いい時代」の中身です。</p>

<h3>リプ欄の証言も、全部同じ構造</h3>

<p>集まった具体例も、見事に一致していました。</p>

<ul>
  <li><strong>「パチスロ40台中5台、平日は誰もいない店で、朝イチ50枚を1枚掛けで全部回しても店員と仲良しだった」</strong></li>
  <li><strong>「毎日30万勝てる台が置いてある店があった」</strong></li>
  <li><strong>「結局ネットで情報が広まったからダメになった」</strong></li>
</ul>

<p><strong>誰も台の演出について語っていません。</strong></p>

<p>語られているのは<strong>「誰もいなかった」「気づかれなかった」「知られていなかった」</strong>という状況です。</p>

<h2>3つ目の証言が、答えを言っている</h2>

<p><strong>「結局ネットで情報が広まったからダメになった」</strong></p>

<p>これが全てだと思います。</p>

<h3>情報が均質化すると、何が起きるか</h3>

<div class="overflow-x-auto my-6">
<table>
  <tr>
    <th>昔</th>
    <th>今</th>
  </tr>
  <tr>
    <td>解析が出るまで数週間〜数か月</td>
    <td>導入直後からネットに並ぶ</td>

  <tr>
    <td>店の傾向は自分で通って掴む</td>
    <td>データサイトで誰でも見られる</td>
  </tr>
  <tr>
    <td>良い台は自分だけが知っている</td>
    <td><strong>全員が同じ情報を持っている</strong></td>
  </tr>
  <tr>
    <td>雑誌が主な情報源</td>
    <td>SNSで即座に共有される</td>
  </tr>

<p><strong>情報の非対称性が、そのまま利益だった。</strong></p>

<p>期待値という概念は昔からありました。<strong>ただ、それを知っている人が圧倒的に少なかった。</strong> だから同じ台を、毎日座っていられた。</p>

<p><strong>今、同じ台があったら何が起きるか。</strong> 初日で投稿され、翌日には行列ができ、3日後には店が対策します。</p>

<h2>これは業界全体の構造とも一致する</h2>

<p>実は、この話は過去に書いた記事といくつも繋がります。</p>

<h3>羽根モノの聖地が生まれなくなった理由</h3>

<p>先日、<strong>1994年の岡山に羽根モノ専門店があった</strong>という記事を書きました。県外からわざわざ通う客がいた店です。</p>

<p>あのとき、<strong>「もうあの種の店は生まれない」</strong>と書きました。理由の一つがこれでした。</p>

<p><strong>「情報が均質化し、わざわざ行く動機が薄い」</strong></p>

<p>特別な場所が成立するには、<strong>そこにしかない何かが必要です。</strong> 情報が共有されると、その「そこにしかない」が消えます。</p>

<h3>「この人は強い」と言われた客</h3>

<p>先日、<strong>元店長が「確率で組んでいるのに勝ち続ける客がいた」と振り返った投稿</strong>も扱いました。</p>

<p>あのとき、こう分析しました。<strong>その人は元プロで、冬は毎日、夏は雨の日に来ていた。客が少ない日を選んでいた。</strong></p>

<p><strong>あれも、独占の話でした。</strong> 客が少ない日を選べば、良い台が残る。<strong>誰も競合していない状況を、自分で作っていた。</strong></p>

<h3>今の期待値稼働は、競争になっている</h3>

<p>対して現在はどうか。</p>

<p>先日、<strong>抽選が1,180人で打ち切られた店</strong>について書きました。<strong>受付開始から15分で上限到達</strong>です。</p>

<p>そして<strong>演者の淘汰</strong>の記事でも触れましたが、発注元のホールは10年で半減しています。<strong>パイが縮むなかで、同じ情報を持った人間が同じ台を奪い合う。</strong></p>

<p><strong>これが「時代が違う」の正体です。</strong></p>

<h2>ユーザーの反応</h2>

<p>この投稿への反応を要約して紹介します。</p>

<ul>
  <li>「台ではなく時代、という指摘が的確すぎる」という声（本質を評価する反応要約）</li>
  <li>「当時は誰もいない店で好き放題打てた。あの環境はもう戻らない」という声（具体例を語る反応要約）</li>
  <li>「ネットで情報が広まったのが全ての原因だと思う」という指摘（情報環境を挙げる反応要約）</li>
  <li>「情報が開かれたこと自体は、初心者にとっては良いことでは」という指摘（別の見方の反応要約）</li>
  <li>「結局は懐古。当時も負けていた人のほうが多かったはず」という指摘（冷静な反応要約）</li>
</ul>

<p>4つ目と5つ目。<strong>ここは公平に扱うべきところです。</strong></p>

<h2>ただし、情報の均質化は悪いことばかりではない</h2>

<p>懐古で終わらせないために、反対側も書きます。</p>

<h3>昔は「知らない人が損をする」時代だった</h3>

<p>独占できたということは、<strong>独占されていた側がいた</strong>ということです。</p>

<div class="overflow-x-auto my-6">
<table>
  <tr>
    <th>当時</th>
    <th>状況</th>
  </tr>
  <tr>
    <td>知っている少数</td>
    <td>日当5万円</td>
  </tr>
  <tr>
    <td>知らない多数</td>
    <td>同じ店で、何も知らずに負けていた</td>
  </tr>
</table>
</div>

<p><strong>「いい時代」だったのは、情報を持っていた側だけです。</strong></p>

<p>今は、ボーダーラインも設定判別も、調べれば誰でも分かります。<strong>初心者が同じ土俵に立てるようになった。</strong> これは明確な進歩でしょう。</p>

<h3>当時も、大半は負けていた</h3>

<p>そしてもう一点。<strong>懐古される時代も、勝っていたのは一握りです。</strong></p>

<p>先日、<strong>元店長の「強い客」の話</strong>を扱ったとき、投稿にはこう書かれていました。<strong>「何を打っても飲まれる客のほうが圧倒的に多く、自分自身も負け側だった」</strong>と。</p>

<p><strong>この一文があるから、あの証言は信頼できました。</strong></p>

<p>今回の「いい時代」も同じです。<strong>日当5万円を稼いでいた人がいた一方で、その裏には何も知らずに打っていた大勢がいます。</strong></p>

<h2>では、今「独占」に相当するものは何か</h2>

<p>実務的な話で締めます。</p>

<p>情報が均質化した今でも、<strong>差がつく領域はまだあります。</strong></p>

<div class="overflow-x-auto my-6">
<table>
  <tr>
    <th>領域</th>
    <th>なぜ差がつくか</th>
  </tr>
  <tr>
    <td>店ごとの運用</td>
    <td>データは公開されているが、読む人は少ない</td>
  </tr>
  <tr>
    <td>資本の把握</td>
    <td>店名が違っても運営会社が同じなら競合しない</td>
  </tr>
  <tr>
    <td>時間帯の選択</td>
    <td>客が少ない時間を狙える人は限られる</td>
  </tr>
  <tr>
    <td>記録の習慣</td>
    <td>誰でもできるが、実際にやる人は少数</td>
  </tr>
</table>
</div>

<p><strong>情報は開かれましたが、「使う人」は今も少数です。</strong></p>

<p>先日、<strong>「打ってる台で性格が分かる」</strong>という記事で書きました。<strong>当たった例だけが記憶に残る</strong>という話です。<strong>多くの人は、公開されているデータを実際には見ていません。</strong></p>

<p><strong>独占は消えました。ただ、差は残っています。</strong></p>

<h2>まとめ：2つの記事を並べると</h2>

<p>前回と今回、2本書きました。整理するとこうなります。</p>

<div class="overflow-x-auto my-6">
<table>
  <tr>
    <th>論点</th>
    <th>結論</th>
  </tr>
  <tr>

  <tr>
    <td>持ち時間</td>
    <td>明確に悪化。玉単価と純増の問題</td>

    <td>勝ちやすさ</td>
    <td>台ではなく店の運用の問題</td>
  </tr>
  <tr>
    <td><strong>環境</strong></td>
    <td><strong>昔のほうが圧倒的に良かった。独占できたから</strong></td>
  </tr>
</table>
</div>

<p><strong>「昔の台が良かった」は、たぶん正確ではありません。</strong> 台は今のほうがよくできている。</p>

<p><strong>「昔の時代が良かった」なら、完全に同意します。</strong> 誰も知らない台を、毎日一人で打てた。<strong>あれはもう、二度と再現できません。</strong></p>

<p>そして、それを壊したのは規制でもメーカーでもなく、<strong>情報が共有されるようになったこと</strong>でした。</p>

<p>便利になった代償として、独占が消えた。<strong>なかなか、身も蓋もない話だと思います。</strong></p>
