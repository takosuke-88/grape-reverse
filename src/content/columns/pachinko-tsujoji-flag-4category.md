  パチンコに「通常時フラグ」と4段階表示　結局、何がどう変わるのか
</h1>
</div>

<p>9月8日、メーカーの業界団体が説明会を開きました。<strong>「通常時フラグ」「4カテゴリ」——正直、この用語だけ見ても何のことか分かりません。</strong></p>

<p>なので今回は、<strong>それが何で、打ち手にとって何がどう変わるのか</strong>だけを、できるだけ噛み砕いて書きます。</p>

<h2>まず、何が発表されたのか</h2>

<p>日工組（日本遊技機工業組合）ならびに日電協（日本電動式遊技機工業協同組合）は9月8日、都内で「パチンコ・パチスロ プレスカンファレンス」を開催しました（出典：<a href="https://p-johojima.jp/" target="_blank" rel="noopener noreferrer">情報島＋</a>）。</p>

<p>発表された内容は、大きく3つです。</p>

<h2>①「通常時フラグ」とは何か</h2>

<h3>今のパチンコは「毎回リセット」されている</h3>

<p>まず前提から。<strong>現在のパチンコは、1回転ごとに独立した抽選をしているだけ</strong>です。</p>

<ul>
  <li>1/319の台なら、毎回1/319</li>
  <li>100回転ハマっても、次の1回も1/319</li>
  <li>500回転ハマっても、やはり1/319</li>
  <li><strong>台は「今までの経過」を覚えていない</strong></li>
</ul>

<p>だから通常時は、基本的に<strong>「回して待つだけ」</strong>になります。演出は出ますが、それは当たりか外れかを演出しているだけで、<strong>状態が変わっているわけではない</strong>。</p>

<h3>そこに「状態」を持てるようにする</h3>

<p>今回の新機能は、ここを変えるものです。</p>

<p>掲示板での解説を借りると、<strong>「通常時フラグという内部状態を最大10個持てるようになった」</strong>という説明が分かりやすいでしょう。</p>

<p>つまり<strong>台が「今こういう状態にいる」という情報を、複数持てるようになる</strong>ということです。</p>

<h3>具体的に何ができるようになるのか</h3>

<p>日工組の技術委員長は、こう説明しています。</p>

<p>最大の狙いは、通常時のゲーム性の拡張により毎変動に新たな期待感と楽しさを創出すること。大当りを待つだけでなく、特定の契機を満たすことで様々な抽選が可能となり、規定ゲーム数や特定のチャンス目、ハズレや連続演出、大当りや確変から通常時への移行など、これまでにない新しいルートから大当りを目指すことが可能になった。</p>

<p><strong>ここ、パチスロを打つ人ならピンとくるはずです。</strong></p>

<p><strong>要するに「ゾーン」や「モード」の概念が、パチンコにも入ってくる</strong>ということです。</p>

<h3>ただし「パチスロ化」ではない</h3>

<p>この点について、団体側は明確に否定しています。</p>

<p>目指すのはパチスロ化ではなく、パチンコ独自の新しいゲーム性を作り出していく部分にある、という説明がなされました。</p>

<p>また、噂されていた特定の仕様については<strong>一定の制限があり実現できない</strong>とも説明されています。何でもありになるわけではありません。</p>

<h3>なぜこれが重要なのか</h3>

<p>ここが本質だと思います。<strong>今のパチンコは、当たるまでの時間がきつすぎる。</strong></p>

<p>これまで書いてきた数字を並べます。</p>

<p><strong>1/399の台で、玉単価2円。</strong> 当たるまでに何も起きない時間が、そのまま財布の減る時間になっている。</p>

<p>先日、<strong>「辞めた人は戻らない」という調査</strong>について書きました。離脱の背景として<strong>「低投資でのビギナーズラックが起きにくい」</strong>という指摘がありました。</p>

<p><strong>通常時フラグは、この「何も起きない時間」に手応えを作る技術</strong>だと理解すればいいと思います。</p>

<h2>②「4カテゴリ」とは何か</h2>

<p>こちらはもっと単純です。<strong>台に「レベル表示」を貼る</strong>という話。</p>

<h3>今のスペック表記は、正直読めない</h3>

<p>初心者の立場で考えてみてください。</p>

<ul>
  <li>1/319、1/349、1/399</li>
  <li>「図柄揃い1/399、大当り確率1/349」</li>
  <li>LT搭載、Cタイム、突入率52%、継続率75%</li>
</ul>

<p><strong>これで「自分に合う台」を選べる人が、どれだけいるでしょうか。</strong></p>

<p>日工組の担当者も、こう述べています。多様なスペックが登場しているが直感的にわかりにくいという課題から、プレイスタイルにあわせて独自の4カテゴリに分類を行った。自身の予算にあわせて最適な機械や環境を選択できる環境にしたい。</p>

<h3>新しい表示はこうなる</h3>

<p>複雑化する遊技機のゲーム性を整理し、出玉性能に応じてLv.1〜Lv.4の4段階に分類。図柄揃い確率や大当たり出玉、LT搭載の有無など様々な要素を加味して日工組が独自に区分し、各カテゴリには名称とカラーを設定した統一ロゴを表示します。</p>

<h3>いつから、どう見られるのか</h3>

<p>新表記については2026年11月以降順次行われ、既存機種も日工組のウェブサイトから確認が可能になります。</p>

<p><strong>既存機種も対象</strong>というのが地味に大きい。今ホールにある台も、後から分類が公開されるということです。</p>

<h2>③「導入強化月間」とは</h2>

<p>そして3つ目。<strong>優しい台を優先的に売る期間を作る</strong>という話です。</p>

<p>2027年2月を「遊びやすいパチンコ・パチスロ導入強化月間」に設定。期間中は、パチンコの「Lv.1」「Lv.2」、パチスロの「BT機」「ノーマルタイプ」「低射幸AT機」を優先的に販売していく、としています。</p>

<p>その前段として、2026年9月22日に東京国際フォーラムで開催される「みんパチ・スロサミ2026」で「遊びやすいパチンコ・パチスロ特設コーナー」を設置。パチンコは「Lv.1」「Lv.2」該当機種、パチスロは「BT機」をそれぞれ20台設置する予定です。</p>

<h3>団体トップの言葉</h3>

<p>日工組の理事長は、こう述べています。</p>

<p>今後は、スタート安定装置やデカヘソといったこれまでの機能と新たな機能を組み合わせることで、「優しくて楽しいパチンコ」を復活させたいと考えている。これからはハイスペック機と、ユーザーに優しいパチンコの両立を徹底して追求していく。</p>

<p><strong>「復活させたい」</strong>という言葉が使われています。裏を返せば、<strong>今はそれが失われているという認識</strong>だということです。</p>

<h3>ただし、勘違いしてはいけない点</h3>

<p><strong>Lv.1が「甘い台」という意味ではありません。</strong></p>

<p>この分類はあくまで<strong>出玉性能による区分</strong>です。<strong>釘や設定がどうなっているかは、まったく別の話</strong>。</p>

<ul>
  <li>Lv.1でも、回らなければ普通に負けます</li>
  <li>Lv.4でも、回れば楽しく打てます</li>
  <li><strong>回転数を数える作業は、何も変わりません</strong></li>
</ul>

<p>ここは、以前から繰り返し書いていることです。<strong>スペックとホールの運用は別問題</strong>。カテゴリ表示は台選びの入口を整理するもので、勝ち負けを保証するものではありません。</p>

<h2>ユーザーの反応</h2>

<p>この発表への反応を要約して紹介します。</p>

<ul>
  <li>「通常時にゾーンができるなら、待つ時間が退屈でなくなりそうだ」という声（期待する反応要約）</li>
  <li>「初心者が台を選ぶ入口としては分かりやすい。良い試みだと思う」という声（表示を評価する反応要約）</li>
  <li>「結局はパチスロに寄せているだけではないか」という指摘（方向性を疑問視する反応要約）</li>
  <li>「優しい台を作っても、ホールが買わなければ意味がない」という指摘（実効性を問う反応要約）</li>
  <li>「遊びやすい台を推す動きは過去にもあったが、定着しなかった」という指摘（過去の経緯を挙げる反応要約）</li>
</ul>

<p>4つ目と5つ目、これは冷静に見ておくべき論点です。</p>

<h2>懸念：本当に定着するのか</h2>

<p>公平に書きます。<strong>この方針、ハードルは低くありません。</strong></p>

<h3>ホールが買うかどうか</h3>

<p>先日、8月の新台データを扱ったときに触れました。<strong>特定日で全体稼働は上がっても、既存の主力機は伸びない。客は新台に偏る。</strong></p>

<p>つまりホールは<strong>稼働が取れる台を買う</strong>。優しい台が並んでも、客が来なければ次は買われません。</p>

<h3>過去にも同じ試みがあった</h3>

<p>業界を分析するアナリストは、以前こう指摘していました。</p>

<p><strong>「ある時は遊パチだと言ってそちらに全振りし、規制が変われば今度はラッキートリガーだと大騒ぎする。その度に、トレンドとは対照的なスペックを好む層がついていけなくなり、結果としてユーザーを自ら振り落としている」</strong></p>

<p><strong>今回も同じ轍を踏まないか。</strong> ここが最大の懸念です。「遊びやすい台」に全振りして、また数年後に逆へ振れるなら、振り落とされる人がまた出ます。</p>

<h3>それでも、方向としては悪くない</h3>

<p>とはいえ、<strong>今回は「両立」という言葉が使われています。</strong> ハイスペック機と優しい台の両方を追求する、と。</p>

<p>先日、<strong>「快適に時間を潰せる環境」こそが求められている</strong>という分析を紹介しました。座って過ごせて、少額から遊べて、たまに当たる。<strong>その需要に応える台が増えるなら、素直に歓迎したいところです。</strong></p>

<h2>まとめ</h2>

<p>3行でまとめます。</p>

<ul>
  <li><strong>通常時フラグ</strong>：当たるまでの退屈な時間に、ゾーンやモードを作れるようになる</li>
  <li><strong>4カテゴリ</strong>：台に「遊びやすさレベル」が表示される（2026年11月以降）</li>
  <li><strong>導入強化月間</strong>：2027年2月、優しい台が優先的に売られる</li>
</ul>

<p><strong>やろうとしていることは、分かりやすい話です。</strong> 当たるまでが長くてきついから、その時間を面白くする。台が選びにくいから、レベル表示をつける。</p>

<p>あとは<strong>実際にホールに並ぶかどうか</strong>。そこは打ち手側の反応にもかかっています。<strong>Lv.1やLv.2の台に人が座れば、次も作られる。</strong> 単純な話です。</p>

<p>11月から表示が始まります。次にホールへ行ったら、台にロゴが付いているか少し気にしてみてください。</p>
