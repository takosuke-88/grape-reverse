<h1 class="text-3xl font-bold mb-6 text-gray-900 dark:text-white">
  大阪のスロット入替率120.5%　閉店が続く週に出た、3つの別の数字
</h1>
</div>

<p>ここ数週間、閉店のニュースばかり書いてきました。<strong>ただ、同じ週に別の数字も出ています。</strong></p>

<p>今日は3つ並べてみます。<strong>方向がバラバラなのが、かえって業界の今を表している気がします。</strong></p>

<h2>①大阪：スロット入替率120.5%</h2>

<p>まず、目を引いたのがこの数字です。</p>

<p>8月の新台導入、大阪府のスロット入替率が120.5％に——業界メディアが9月15日に配信した見出しです（出典：<a href="https://p-johojima.jp/" target="_blank" rel="noopener noreferrer">情報島＋</a>）。</p>

<h3>120.5%とは、どういう意味か</h3>

<p>算出の詳細は記事本体で示されているため、ここでは<strong>「100%を超えている」という事実</strong>だけを扱います。</p>

<p>入替率は、基本的に<strong>入れ替えた台数 ÷ 設置台数</strong>です。</p>

<div class="overflow-x-auto my-6">
<table>
  <tr>
    <th>数値</th>
    <th>意味</th>
  </tr>
  <tr>
    <td>50%</td>
    <td>設置台数の半分を入れ替えた</td>
  </tr>
  <tr>
    <td>100%</td>
    <td>全台が1回入れ替わった計算</td>
  </tr>
  <tr>
    <td><strong>120.5%</strong></td>
    <td><strong>全台を入れ替えてもなお足りない規模</strong></td>
  </tr>
</table>
</div>

<p><strong>設置台数を上回る台数を動かしている。</strong> これは相当な水準です。</p>

<h3>つまり、大阪は「回して戦っている」</h3>

<p>先日、8月の新台データを扱ったときに書きました。<strong>特定日で全体稼働は上がっても、既存の主力機は伸びない。客は新台に偏る。</strong></p>

<p>この構造が本当なら、<strong>入れ替え続けるしか集客の手段がありません。</strong></p>

<p>そして大阪は、今まさに<strong>大型店の閉店が相次いでいる地域</strong>です。</p>

<ul>
  <li>キョーイチミナミ店（1,403台）が9月23日で閉店、クレーンゲーム店へ転換</li>
  <li>京一高槻店（1,041台）が同じ9月23日で閉店</li>
</ul>

<p><strong>2,444台が消える地域で、残った店は入替率120.5%で戦っている。</strong></p>

<p>この対比、なかなか強烈です。<strong>脱落する店と、回し続ける店。</strong> 同じ府内で、正反対のことが起きています。</p>

<h3>ただし、これは持続可能なのか</h3>

<p>ここは冷静に見ておきたいところです。</p>

<p><strong>2025年の遊技機販売は1台あたり平均48.4万円。</strong> 入替率120.5%ということは、設置台数分以上の機械代が発生しているということです。</p>

<p>先日、法人半減の記事で触れました。<strong>赤字企業の54.7%が2期連続赤字。</strong> この負担に耐えられる店と、耐えられない店の差が、そのまま閉店として表面化しているのでしょう。</p>

<p><strong>入替率の高さは、活気の証拠であると同時に、消耗戦の証拠でもあります。</strong></p>

<h2>②岐阜：災害協定で地域に残る</h2>

<p>同じ9月15日、まったく違う方向のニュースも出ていました。</p>

<p>岐阜県遊協、県・県警と災害時協定を締結 県内全店舗が駐車場などを無償提供へ（出典：<a href="https://yugi-nippon.com/pachinko-news/post-79417/" target="_blank" rel="noopener noreferrer">遊技日本</a>）。</p>

<p>この件は先日詳しく書きました。要点だけ再掲します。</p>

<p><strong>大阪が「回して戦う」なら、岐阜は「地域に残る」という戦い方です。</strong></p>

<p>どちらが正しいという話ではありません。<strong>ただ、生き残り方の選択肢が複数あることは示されています。</strong></p>

<h2>③メーカー：新台とオフィスに投資</h2>

<p>そして3つ目。<strong>メーカー側も動いています。</strong></p>

<h3>藤商事『eとある魔術の禁書目録3』</h3>

<p>藤商事は「eとある魔術の禁書目録3」（型式名：eとある魔術の禁書目録3RHZ、オレンジ製）を発表しました。当選確率は約1/348の2種タイプで、ST突入確率は50%、TOTAL継続率は約75%となっています。</p>

<p>特徴は<strong>ST が3段階に分かれている</strong>ことです。</p>

<div class="overflow-x-auto my-6">
<table>
  <tr>
    <th>段階</th>
    <th>名称</th>
    <th>抽選回数</th>
  </tr>
  <tr>
    <td>前半</td>
    <td>LIMIT BREAK CHANCE</td>
    <td>30回</td>
  </tr>
  <tr>
    <td>後半</td>
    <td>とある魔術の最強激突ヒーローズラッシュ</td>
    <td>100回</td>
  </tr>
  <tr>
    <td>最終</td>
    <td>LAST CHANCE</td>
    <td>1回</td>
  </tr>
</table>
</div>

<p>そして、<strong>各段階でスペックが違います。</strong></p>

<p>「LIMIT BREAK CHANCE」中の大当りは50％が3,000個（残りは1,500個）で、さらに50%で1,500個の上乗せループが発生。「ヒーローズラッシュ」中の大当りはALL3,000個。「LAST CHANCE」では成功でSTリスタートとなる仕組みです。</p>

<p>ホール導入は11月2日を予定。筐体も新しくなり、スマートハンドルやイヤホンジャックを搭載するとされています。</p>

<p><strong>ちなみに、この機種の系譜は今年好調です。</strong> 8月導入の『スマスロ とある魔術の禁書目録2』は、8月のスロット新台導入で首位を取り、お盆の稼働ランキングでも1位でした。</p>

<h3>設備投資も動いている</h3>

<p>同じ時期、<strong>ダイコク電機が九州の新オフィス「Q-STA」のお披露目会</strong>を行ったことも報じられています。</p>

<p><strong>メーカー側は、新台にもオフィスにも投資している。</strong> ホールが消耗戦を戦っている一方で、供給側は動いているわけです。</p>

<p>でも実際には、<strong>同じ週にこれだけ違う動きが同時に起きている。</strong></p>

<h3>ただし、全部つながっている</h3>

<p>公平に書くと、この3つは無関係ではありません。</p>

<ul>
  <li><strong>メーカーが新台を出す</strong> → ホールが買う → 機械代の負担が増える</li>
  <li><strong>入替率が上がる</strong> → 買えない店が脱落する → 閉店が増える</li>
  <li><strong>店が減る</strong> → 残った店の社会的役割が問われる → 災害協定のような動きが出る</li>
</ul>

<p><strong>3つの動きは、同じ循環の別の断面です。</strong></p>

<h2>ユーザーの反応</h2>

<p>これらの動きへの反応を要約して紹介します。</p>

<ul>
  <li>「入替率120%超えは異常。それだけ必死ということだろう」という指摘（数字に驚く反応要約）</li>
  <li>「大阪で大型店が2つ消える一方で、この数字が出るのが業界らしい」という指摘（対比を挙げる反応要約）</li>
  <li>「入れ替え続けても客が増えないなら、ただの消耗では」という指摘（実効性を疑う反応要約）</li>
  <li>「災害協定のような取り組みは、もっと知られてほしい」という声（地域貢献を評価する反応要約）</li>
  <li>「メーカーが投資できているうちは、まだ業界は動く」という声（前向きに捉える反応要約）</li>
</ul>

<p>3つ目。<strong>これが最も本質的な問いだと思います。</strong></p>

<h2>打ち手として、どう受け止めるか</h2>

<p>実務に落とします。</p>

<p>とくに1行目。<strong>入替率が高い＝甘い、ではありません。</strong> むしろ逆で、<strong>買った分を回収する必要が出ます。</strong></p>

<p><strong>新台が多い店ほど、回転数を厳しく見るべきです。</strong></p>

<h2>まとめ</h2>

<p>大阪は台を回して戦い、岐阜は地域に残る道を選び、メーカーは新台とオフィスに投資している。<strong>同じ週の話です。</strong></p>

<p>閉店の記事ばかり書いていると、つい<strong>「終わりに向かっている」という視点になりがち</strong>です。実際、店舗数も法人数も減り続けています。</p>

<p>ただ、<strong>その裏側でこれだけの動きがある。</strong> 沈むだけではなく、形を変えながら続いている部分も確実にあります。</p>

<p><strong>問題は、入替率120.5%という消耗戦が、いつまで続けられるか。</strong> そこが次の数年を決めるのだと思います。</p>

<p>とりあえず11月2日には新しい台が出ます。<strong>そのときまた、回転数を数えに行きます。</strong></p>
